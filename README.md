## The patch note

> v1.4.2: fixed a bug where the brain replayed your most embarrassing memory from 2009 at 3am instead of running sleep mode.

## Why this bug

The brain's sleep mode has a well-known defect: instead of shutting down
at 3am, it replays your most embarrassing memory from years ago, in full
detail, with no skip button. The fix is stated as a shipped release note
in the terse register of a real changelog: version number, "fixed a bug
where", and a dry description of the symptom. The joke lands on the first
read because the bug is instantly recognisable and the fix sounds like
something an engineer would actually ship.
